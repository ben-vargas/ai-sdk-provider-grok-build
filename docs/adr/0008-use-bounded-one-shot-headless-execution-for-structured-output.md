# Use bounded one-shot headless execution for structured output

Headless calls use a temporary prompt file, serialize roles, textual files, and completed tool history as an explicit transcript, and warn while omitting unsupported media, binary or custom parts, and private reasoning. Streaming NDJSON is parsed incrementally without whole-response buffering, while native schema output alone is buffered under a byte limit and emitted as one final JSON payload. Every headless prompt is bounded by `timeouts.promptMs` when configured and uses the same `SIGTERM` to `SIGKILL` escalation as cancellation.

The original JSON Schema is passed unchanged for constrained output; schema-less JSON remains prompt guidance with a compatibility warning. Legacy structured wrappers give explicit `structuredOutput` or `structured_output` fields precedence, including an explicit `null`. Otherwise an own `result` property is authoritative: `{ result: null }` emits `"null"`, while `{ result: null, text: "..." }` retains the observed legacy fallback only when `text` is a string. A wrapper with no structured, result, or text payload fails with `AcpProtocolError`. The input mapping and its warnings remain transport-neutral because the same mapping serves ACP and headless execution.
